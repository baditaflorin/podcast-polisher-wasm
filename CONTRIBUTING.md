# Contributing

Thanks for helping improve Podcast Polisher WASM.

## Local workflow

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `make install-hooks`.
4. Use Conventional Commits for commit messages.
5. Run `make test` and `make smoke` before pushing.

No secrets belong in this repository. Use `.env.example` for placeholders only.
