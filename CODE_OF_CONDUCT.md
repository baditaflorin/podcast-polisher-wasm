# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Standards

Use welcoming language, respect different viewpoints, accept constructive feedback, and focus on what is best for the community.

Unacceptable behavior includes harassment, insults, threats, sustained disruption, or publishing private information without permission.

## Enforcement

Project maintainers may remove comments, commits, issues, or other contributions that do not align with this Code of Conduct.
