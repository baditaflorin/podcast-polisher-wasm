# 0070 - Documentation Reality Alignment Process

## Status

Accepted

## Context

Phase 3 requires README and in-app claims to match tested behavior.

## Decision

README claims must be tied to tested or audited workflows. Unsupported pathways are listed as limitations instead of implied by vague copy.

## Consequences

The documentation becomes less magical and more useful for a stranger deciding whether the app fits their file.

## Alternatives Considered

- Keep aspirational README language: rejected because it creates support debt.
